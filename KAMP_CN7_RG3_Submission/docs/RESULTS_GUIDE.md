# 공식 무라벨 테스트 예측 결과 설명

## 결과를 보는 방법

CN7·RG3 제품별 CSV와 통합 CSV의 각 행에는 **실제 공정 센서값 → 센서 기반 제품 분류 → 제품별 모델 점수 → 검사순위 → F1.5 이진 품질 의심 판정**이 나란히 담겨 있습니다. 출력은 `Record_ID`와 **원본 영어 피처명을 유지한 모델 입력 센서 23개**, 모델이 추가한 영어 결과 7열만 포함합니다. 원본에서 모델이 쓰지 않는 `Clamp_Open_Position`은 제외했습니다. 통합 CSV는 제품별 원래 순서를 유지하면서 35~180행 단위로 섞었습니다. 제품별 파일의 결과는 통합 파일에서 해당 제품 행을 추린 것과 같습니다.

| 모델이 추가한 열 | 읽는 방법 |
| --- | --- |
| `Predicted_Product` | 센서만으로 분기한 CN7 또는 RG3 |
| `Predicted_PassOrFail` | `0`=정상 예측, `1`=불량 의심 |
| `Predicted_Quality` | `PASS_PREDICTED` 또는 `FAIL_SUSPECT` |
| `Inspection_Rank` | 제품별 검사 우선순위. 1이 최우선 |
| `Inspection_Tier` | 순위에 따른 상위 5%, 5~10%, 10~20%, 이후 범위 |
| `Model_Score` | 제품별 모델의 원점수. 제품 간 직접 비교 또는 확률 해석 불가 |
| `Priority_Score` | 순위를 0~1로 바꾼 판정점수. 불량확률 아님 |

`Inspection_Tier`의 값: `TOP_5_PCT`(상위 5%), `TOP_5_TO_10_PCT`(5~10%), `TOP_10_TO_20_PCT`(10~20%), `AFTER_TOP_20_PCT`(20% 이후), `AFTER_TOP_20_PCT_FAIL_SUSPECT`(20% 이후에도 불량 의심). `Record_ID`는 원본 CSV 첫 열 `Unnamed: 0`의 값 그대로입니다.

## F1.5 판정 결과

| 제품 | 전체 | 정상 예측(0) | 불량 의심(1) | 의심 비율 | 판정점수 기준 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CN7 | 35,239 | 34,714 | 525 | 1.49% | ≥ 0.9851239669421488 |
| RG3 | 35,941 | 27,146 | 8,795 | 24.47% | ≥ 0.7552921253175275 |
| 합계 | 71,180 | 61,860 | 9,320 | 13.09% | 제품별 기준 적용 |

이 수는 실제 불량 건수가 **아닙니다.** 공식 테스트 CSV에는 정답 `PassOrFail`이 없어 테스트 Precision·Recall·F1을 계산할 수 없습니다. 임계값은 제공된 F1.5 정책 joblib의 값이며, 점수는 모델 순위를 배치 내 0~1로 변환한 상대 점수이지 불량확률이 아닙니다. **0/1의 개수 자체는 배치 크기와 고정 임계값에 의해 거의 결정**되고, 모델은 *어떤* 행이 1이 되는지를 결정합니다.

## 모델 순위와 검사역량의 관계

| 제품 | 상위 5% | 5~10% | 10~20% | 20% 이후 | 20% 이후에도 불량 의심 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CN7 | 1,761 | 1,762 | 3,524 | 28,192 | 0 |
| RG3 | 1,797 | 1,797 | 3,594 | 28,753 | 1,607 |

RG3 F1.5 기준은 약 24.5%를 불량 의심으로 판정하므로, **검사역량 Top 20% 밖의 1,607행도 불량 의심**입니다. CSV에는 이를 `AFTER_TOP_20_PCT_FAIL_SUSPECT`로 표시합니다. 20% 검사 역량을 절대 제한으로 운영한다면 이 1,607행에 대한 추가 검토 방침이 필요합니다. 별도의 검토 방침 없이 20% 뒤의 행을 정상 확정으로 취급해서는 안 됩니다.

## 제공된 labeled 검증 근거

| 제품 | labeled 검증 범위 | TP / FP / FN / TN | Precision | Recall | F1 | F1.5 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| CN7 | 1,211행, 불량 17개; 그룹 분리 OOF | 9 / 10 / 8 / 1,184 | 47.37% | 52.94% | 0.5000 | 0.5109 |
| RG3 | 1,182행, 불량 25개; 5회 반복 그룹 OOF 평균 순위 | 14 / 276 / 11 / 881 | 4.83% | 56.00% | 0.0889 | 0.1314 |

위 값은 **threshold 선택에 사용된 개발 데이터의 OOF 요약**입니다. 모델 선택·임계값 선택의 영향이 있으므로 처음 보는 현장 데이터의 보장 성능이 아닙니다. RG3는 검증에서도 오탐이 많습니다. 23개 사용 센서 중 하나 이상이 각 제품의 labeled 학습 범위를 벗어나는 공식 테스트 행이 CN7 61.55%, RG3 51.24%여서 적용 데이터 차이가 큽니다. 특히 RG3의 동일 센서·연속 ID 쌍 신호가 labeled에서 약 97.12%, 공식 테스트에서는 약 34.68%에 적용되어 전이 성능이 불확실합니다.

## 자동 검사 항목

- 입력 71,180행 전부 처리, 제품 출처와 센서 기반 분기 일치 71,180행, 제품 분기 보류 0행. 단, 제품 분기 모델 자체가 공식 파일의 출처 라벨로 학습했으므로 독립 분류 정확도는 아닙니다.
- 각 제품의 검사순위는 1~N 중복 없이 한 번씩 나타납니다.
- 제공된 `Submission_FINAL_F15.zip`의 F1.5 결과와 CN7 35,239행, RG3 35,941행의 검사순위와 이진판정이 각각 전부 같습니다. 의존성은 XGBoost 3.1.3으로 고정했습니다.
- `Predicted_PassOrFail`은 제품별 두 값(0/1)이 모두 존재하며, **동봉 joblib의 threshold와 실제 모델 순위 점수**를 비교한 값과 모든 행에서 일치합니다.
- 제품별 파일의 공정 수치는 해당 원본 CSV와 일치하고, 통합 파일에서 제품별 행을 뽑으면 같은 결과입니다.
- 빈 결과 셀 0개. 모든 행 `True` 같은 고정 검사 플래그는 결과 파일에 없습니다.

이 검사는 **코드·파일 일관성** 확인입니다. 정답이 없는 무라벨 테스트에서 불량 검출 성능을 측정한 것은 아닙니다.
